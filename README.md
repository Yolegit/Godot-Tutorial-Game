Godot Tutorial Game
This project was built by following a YouTube tutorial to learn the fundamentals of the Godot game engine.
I built this project as a way to become familiar with Godot’s editor, scenes, nodes, sprites, collisions, animations, scripting, and other core game-development concepts before beginning an original game for the TSA Game Development competition.
This is a tutorial project, not an original game. The purpose of the repository is to document my learning process and provide a reference for the Godot concepts I learned while building it.
